Built for focused work

Native performance

Rust and GPU-accelerated UI keep the editor responsive while large projects stay open.

Language intelligence

Language servers provide completion, diagnostics, rename, go-to definition, formatting, and code actions.

Git, close at hand

Browse changes, stage files, inspect history, resolve conflicts, and commit without leaving the workspace.

Terminal and tasks

Run shells, build commands, tests, and project tasks in integrated terminal panes with the current project context.

Debugging and REPL

Use DAP debuggers and interactive REPL workflows alongside the code you are inspecting.

Modes and themes

Shape the editor with Vim or Helix modal editing, keymaps, themes, icon themes, and extensions.

Documentation, inside the editor

The built-in documentation covers the editor from first launch to advanced workflows. These are the guides you can use when you want to go deeper.

Start and configure

Learn the command palette, key bindings, snippets, toolchains, language settings, themes, icon themes, and visual customization.

Write and navigate

Use multibuffers, the outline panel, completions, diagnostics, tab switching, Vim mode, Helix mode, and SuperTab.

Build and ship

Run tasks and terminal commands, work with Git, inspect debugger sessions, and use REPL workflows including notebooks.

Connect and extend

Develop over SSH, configure language servers, and add language, debugger, theme, and icon capabilities from source.

Supported platforms

Use the same workspace across macOS, Linux, Windows, and FreeBSD, with native packages and source builds where available.

Principles

No telemetry, proprietary server dependency, forced sign-in, involuntary updates, or distracting collaboration layer. Your tools stay yours.

Quick start

Clone the source and build with the pinned Rust toolchain:

git clone https://github.com/monyacode/monyacode
cd monyacode
cargo run --release
